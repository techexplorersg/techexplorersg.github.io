# Satwik Gudapati AI/ML Portfolio — Free GitHub Pages

## Publish for free
1. Create a **public** repository named `techexplorersg.github.io` on your GitHub account.
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root.
3. Open **Settings → Pages** and set the source to **GitHub Actions**.
4. Push the files to the `main` branch.
5. Open `https://techexplorersg.github.io/`.

No paid hosting, build service, database, API key, or custom domain is required.

## Resume
The site currently links to the supplied DOCX resume. For the best recruiter experience, export the resume to PDF and update the link in `index.html`.
